:::note[Objectif de l'exercice]
Ajouter l'**avertisseur sonore** qui alerte les agents au-delà de 40 °C (exigence EF4), puis organiser `loop()` pour que la surveillance soit **continue**.
:::

Ajoutez un **buzzer** qui émet un son lorsque la température dépasse **40 °C**.

## Câblage

Partez d'une copie du projet de l'exercice 9 et ajoutez :

| Buzzer | Relier à |
|---|---|
| broche 2 (+, fil rouge) | **D8** |
| broche 1 (−, fil noir) | **GND** |

## Programme

Le buzzer de Wokwi est **passif** : il ne sonne que si on lui envoie un signal périodique. La fonction `tone(broche, fréquence)` produit ce signal ; `tone(broche, fréquence, durée)` s'arrête seule après la durée indiquée ; `noTone(broche)` coupe le son.

```cpp
const int buzzerPin = 8;
const float SEUIL_ALARME = 40.0;  // °C

// Dans loop(), après une mesure :
if (temperature > SEUIL_ALARME) {
  tone(buzzerPin, 1000);  // 1 kHz
} else {
  noTone(buzzerPin);
}
```

Portez la température du capteur à 42 °C, puis ramenez-la à 30 °C.

Proposez une nouvelle organisation de `loop()` qui sépare la **surveillance** (mesure toutes les 2 s, LED, buzzer) de l'**affichage** (écran LCD à la demande).

## Critères de validation

- [ ] Le buzzer sonne au-dessus de 40 °C et se tait au-dessous.
- [ ] Après réorganisation de `loop()`, l'alarme se déclenche **sans** appui sur le bouton, et le bouton met toujours l'écran à jour.
- [ ] Les questions Q10.1 à Q10.3 ont une réponse justifiée.
