## Basculer entre deux unités

Partez d'une copie du projet de l'exercice 10 et ajoutez un **interrupteur coulissant** qui bascule l'affichage de la température entre **degrés Celsius** et **degrés Fahrenheit**.

| Interrupteur coulissant | Relier à |
|---|---|
| broche 1 | **D7** |
| broche 2 (commun) | **GND** |

Configurez D7 en `INPUT_PULLUP`. Interrupteur à gauche (position par défaut), D7 est relié à GND et lit LOW : affichage en °C. À droite, D7 lit HIGH : affichage en °F. La conversion s'écrit **°F = °C × 9 / 5 + 32**.

</Question>

</Question>

## Le programme final du contrôleur

Réunissez tout ce que vous avez construit depuis l'exercice 6 dans un seul programme. En plus des exigences **EF1 à EF5**, il doit respecter les règles de réalisation suivantes.

| Règle | Description |
|---|---|
| P1 | La mesure a lieu toutes les 2 s **sans `delay()`** dans `loop()` : utilisez `millis()` (exercice 2). |
| P2 | La LED RVB et le buzzer sont mis à jour après **chaque mesure**, sans attendre un appui sur le bouton (exercice 10). |
| P3 | Un appui sur le bouton affiche la dernière mesure sur l'écran : **un appui = un seul affichage** (exercice 9). |
| P4 | L'unité ne change que l'**affichage** (écran et moniteur série) ; les seuils et les comparaisons restent en °C (exercice 11). |
| P5 | Les broches, les seuils et les durées sont des **constantes nommées** ; chaque fonction a un seul rôle (mesurer, signaler, alerter, afficher). |

Vous pouvez partir de cette organisation de `loop()` :

```cpp
const unsigned long PERIODE_MESURE = 2000;  // ms (EF1)
unsigned long instantMesure = 0;            // date de la dernière mesure

void loop() {
  const unsigned long maintenant = millis();

  // Surveillance : toutes les 2 s, que l'on appuie ou non sur le bouton
  if (maintenant - instantMesure >= PERIODE_MESURE) {
    instantMesure += PERIODE_MESURE;
    readSensorData();    // EF1
    afficherZone();      // EF2 : couleur de la LED RVB
    gererAlarme();       // EF4 : buzzer
    afficherSerie();     // suivi sur le moniteur série
  }

  // Affichage à la demande
  if (appuiBouton(maintenant)) {  // front descendant, rebonds filtrés
    displayDataOnLCD();           // EF3 et EF5
  }
}
```
