## L'architecture du programme

Le code de départ ne contient **aucune attente** dans `loop()`. Chaque tâche fait un petit travail puis rend la main : c'est un **ordonnancement coopératif**. Un tour de boucle dure moins d'une milliseconde, sauf quand le capteur est lu.

```cpp
void loop() {
  // TODO B4 : réarmer le chien de garde
  const unsigned long maintenant = millis();

  lireConsole();                                   // commandes reçues, sans attendre
  surveillerBoitier(maintenant);                   // contact d'ouverture (partie C)
  if (appuiBouton(maintenant)) acquittementLocal();

  if (maintenant - tAcquisition >= PERIODE_ACQ_MS) {   // toutes les 2 s
    tAcquisition += PERIODE_ACQ_MS;
    acquerir(maintenant);
  }
  gererSession(maintenant);                        // expiration de la session (partie C)

  const uint8_t nouvelEtat = calculerEtat();       // état le plus prioritaire
  if (nouvelEtat != etat) {
    etat = nouvelEtat;
    telemetrieImmediate = true;                    // trame sur changement d'état (partie D)
  }
  // ... télémétrie périodique, LED, buzzer, écran
}
```

La fonction `calculerEtat()`, fournie, choisit l'état affiché selon un ordre de **priorité** : INTRUSION, puis DÉFAUT CAPTEUR, puis l'état thermique.

## B2. Défaut capteur (SÛR-1)

## B4. Chien de garde (SÛR-4)

Le **chien de garde** (*watchdog*) est un minuteur matériel, indépendant du programme. S'il n'est pas **réarmé** avant l'échéance (ici 2 s), il **redémarre** le microcontrôleur. Un programme bloqué ne passe plus par l'instruction de réarmement : la carte repart d'elle-même au lieu de rester figée.

Le début de `setup()` est fourni :

```cpp
const uint8_t causeReset = MCUSR;  // registre des causes du dernier redémarrage
MCUSR = 0;
wdt_disable();                     // après un redémarrage par le chien de garde, celui-ci reste actif
```

Ajoutez `wdt_enable(WDTO_2S);` à la **fin** de `setup()` et `wdt_reset();` au **début** de `loop()` (`TODO B4`). Testez avec `TEST BLOCAGE`, en session : environ 2 s plus tard, la carte redémarre et affiche `# EVT DEMARRAGE 8` (le bit WDRF de MCUSR) puis `# Redemarrage provoque par le chien de garde`.

:::caution[Sur une vraie carte]
Sur une carte UNO réelle, le chargeur d'amorçage (*bootloader*) s'exécute avant votre programme et peut **effacer MCUSR** : la cause du redémarrage n'est alors plus lisible. Wokwi charge directement le programme, sans bootloader.
:::
