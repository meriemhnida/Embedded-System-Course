## MicroPython : Python sur microcontrôleur

Dans l'écosystème de la Raspberry Pi Pico, une alternative au langage **C** est **MicroPython**. MicroPython est une version de Python adaptée, on dit aussi **portée**, pour fonctionner dans un environnement particulier : les microcontrôleurs. Cette alternative offre une approche plus simple aux programmeurs qui connaissent déjà Python.

:::caution[À retenir]
**MicroPython** est une implémentation du langage Python **optimisée pour les microcontrôleurs**. Elle offre la puissance et la simplicité d'un langage de **haut niveau**, adaptées à des ressources limitées : quelques centaines de kilo-octets de mémoire vive, pas de système d'exploitation.
:::

L'idée derrière MicroPython est de disposer d'un **langage de haut niveau porté sur microcontrôleur**. Le chapitre 3 en donne une première présentation : [la famille Raspberry Pi](/Embedded-System-Course/parcours/chapitre-3/01-famille-raspberry-pi/).

## Préparation : Wokwi pour la Pi Pico

Sur une vraie carte, la Pico se programme en MicroPython par son port **micro-USB**, avec l'IDE **Thonny**. Dans ce TP, vous utilisez **Wokwi**, le simulateur en ligne déjà employé au chapitre 2 : le montage et le code se font sur la même interface web.

1. Ouvrez [wokwi.com](https://wokwi.com/) et connectez-vous avec votre **compte GitHub**.
2. Créez un projet par exercice et nommez-le clairement, par exemple `Pico-Ex03-Dupont-Martin`.
3. Quand un exercice complète le montage du précédent, partez d'une **copie** du projet précédent (« Save a copy »).

:::tip[Pour aller plus loin]
Pour programmer plus confortablement, vous pouvez utiliser l'extension **Wokwi pour VS Code** : le simulateur s'ouvre alors directement dans l'éditeur.
:::
