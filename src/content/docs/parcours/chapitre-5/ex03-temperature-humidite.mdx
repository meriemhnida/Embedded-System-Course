## Câblage

| DHT22 | Relier à la Pico |
|---|---|
| VCC | **3V3** (3V3 OUT) |
| SDA (données) | **GP15** |
| NC | rien (non connectée) |
| GND | **GND** |

## Étape 1 : lire et afficher

En vous basant sur le code ci-dessous, réalisez le montage permettant de mesurer la température et l'humidité, et d'imprimer les valeurs dans la console.

```python
from dht import DHT22
from machine import Pin
from time import sleep

dht = DHT22(Pin(15))

try:
    while True:
        # Mesurer la température et l'humidité
        dht.measure()
        temp = dht.temperature()
        hum = dht.humidity()

        # Afficher la température et l'humidité sur la console
        print(f"Température : {temp} °C   Humidité : {hum} %")

except KeyboardInterrupt:
    pass
```

Lancez la simulation, puis cliquez sur le capteur : des curseurs permettent de **modifier la température et l'humidité**. Vérifiez que la console suit vos réglages.
