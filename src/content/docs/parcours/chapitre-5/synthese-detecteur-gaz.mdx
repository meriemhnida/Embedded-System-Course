## Le besoin

Nous souhaitons construire une application embarquée qui nous **prévient en cas de fuite de gaz**. Un capteur simule un **détecteur de gaz** qui déclenche une **alarme** en cas de fuite. L'alarme sonne **jusqu'à ce que la fuite soit stoppée**. De plus, des LED s'allument en fonction de la **quantité de gaz** détectée par le capteur.

### Cahier des charges

| Exigence | Description |
|---|---|
| EF1 | Mesurer en continu la concentration de gaz avec le capteur **MQ-2** de Wokwi. |
| EF2 | En cas de fuite, déclencher une **alarme sonore** qui retentit tant que la fuite n'est pas stoppée. |
| EF3 | Si une **grande quantité** de gaz fuit, allumer la LED **rouge** et la faire **clignoter**. |
| EF4 | Si la fuite est **faible**, allumer la LED **orange** (fixe). |
| EF5 | En l'absence de fuite, allumer la LED **verte** et couper l'alarme. |

### Affectation des broches

| Composant | Pi Pico | Arduino UNO |
|---|---|---|
| Capteur de gaz MQ-2 : VCC | **3V3** | **5V** |
| Capteur de gaz MQ-2 : AOUT | **GP26** (ADC0) | **A0** |
| Capteur de gaz MQ-2 : GND | **GND** | **GND** |
| LED verte, via 220 Ω | **GP10** | **D10** |
| LED orange, via 220 Ω | **GP11** | **D11** |
| LED rouge, via 220 Ω | **GP12** | **D12** |
| Buzzer (+), l'autre broche vers GND | **GP13** | **D8** |

Dans Wokwi, cherchez le composant **Gas Sensor (MQ2)**. Pendant la simulation, cliquez dessus pour régler la concentration de gaz, en **ppm** (parties par million).

:::tip[Faire sonner le buzzer en MicroPython]
Un buzzer piézo a besoin d'un signal **périodique**. Sur la Pico, utilisez une sortie **PWM** :

```python
from machine import Pin, PWM

buzzer = PWM(Pin(13))
buzzer.freq(1000)          # son de 1000 Hz
buzzer.duty_u16(32768)     # 50 % : le buzzer sonne
buzzer.duty_u16(0)         # 0 % : silence
```

Sur l'Arduino, utilisez `tone()` et `noTone()`, comme au [TP1](/Embedded-System-Course/parcours/chapitre-2/tp1/ex10-avertisseur-sonore/).
:::
