## Explorez la carte

Voici le Raspberry Pi 5 vu de dessus, avec les broches GPIO en haut. **Passez la souris** sur un composant (ou sur son étiquette) pour un aperçu rapide, puis **cliquez dessus** pour lire son explication.

Le bouton **Visite guidée : suivant** vous fait parcourir tous les composants dans l'ordre. Les boutons de couleur au-dessus de la carte servent à **mettre en évidence** une seule famille de composants. Sur téléphone, vous pouvez aussi choisir un composant dans la liste sous le schéma.

## Les composants par famille

| Famille | Composants |
|---|---|
| **Traitement et mémoire** | Microprocesseur (CPU), Mémoire, Southbridge |
| **Connectique** | Ports GPIO, Ports USB, Ports USB 3, Bus PCIe, Ethernet Gigabit, Port série, Sortie vidéo HDMI, Ports caméra et afficheurs LCD |
| **Alimentation** | USB-C (alimentation), Connecteur batterie, PoE |
| **Sans fil** | WiFi / Bluetooth |
| **Commande et signalisation** | Bouton Power, LED d'état, Ventilateur |

## Localiser les broches et le processeur

Deux repères sont à retenir, car ils servent dans la suite du chapitre :

- les **broches (pins) GPIO** — *General Purpose Input/Output*, entrées/sorties à usage général — sont alignées le long du bord supérieur de la carte ;
- le **processeur (CPU)** est le **Broadcom 2712ZPKFSB00C1t**, la grande puce métallique au centre de la carte.

:::note[Le processeur]
Le Raspberry Pi 5 est équipé d'un processeur quadricœur Cortex-A76 cadencé à 2,4 GHz, accompagné d'un GPU VideoCore VII, et prend en charge le PCIe.
:::
