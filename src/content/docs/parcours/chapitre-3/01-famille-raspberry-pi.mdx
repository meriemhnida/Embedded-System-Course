## Pi Pico, Pi Pico W et MicroPython

Dans l'écosystème de la **Raspberry Pi Pico**, une alternative au langage C est **MicroPython**.

**MicroPython** est une version spécifique de Python, adaptée pour fonctionner dans un environnement particulier : les **microcontrôleurs**. C'est une implémentation du langage de programmation Python, optimisée pour les microcontrôleurs : elle offre la puissance et la simplicité de Python (un langage de haut niveau), tout en restant adaptée à des ressources limitées.

:::tip[En une phrase]
MicroPython, c'est un **langage de haut niveau porté sur microcontrôleur**.
:::

### La Raspberry Pi Pico W

La **Pico W** est une carte de développement **compacte** qui intègre une **connectivité WiFi** et repose sur le microcontrôleur **RP2040**.

## Le Raspberry Pi 5

Le **Raspberry Pi 5** (2023) est équipé :

- d'un processeur **quadricœur Cortex-A76** cadencé à **2,4 GHz** ;
- d'un **GPU VideoCore VII** ;
- d'une prise en charge du **PCIe** ;
- de **2, 4, 8 ou 16 Go** de RAM, selon le modèle.

Le prochain **Raspberry Pi 6** est prévu pour fin 2026 – début 2027.

La suite de ce chapitre est consacrée à la carte Raspberry Pi 5 : ses composants, ses broches GPIO, puis les protocoles de communication I2C, SPI et UART.
