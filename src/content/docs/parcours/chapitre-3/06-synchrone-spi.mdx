## Fiche SPI

**SPI** signifie *Serial Peripheral Interface*.

| | |
|---|---|
| **Nombre de fils** | 4 (MOSI, MISO, SCK, CS) |
| **Type** | communication série **synchrone** |
| **Avantages** | très rapide, stable |
| **Limites** | plus de fils, une broche CS par périphérique |

Le SPI est **plus rapide** que l'I2C, mais il utilise **plus de fils** (4 fils).

## Le câblage

Trois fils sont **partagés** par tous les périphériques ; chaque périphérique a en plus **son propre fil de sélection** (CS, *Chip Select*). Dans la figure, le Pi choisit tour à tour le premier, puis le second périphérique : seul celui dont la ligne CS est activée communique.

| Fil | Signification | Rôle |
|---|---|---|
| **MOSI** | *Master Out Slave In* | Le Pi **envoie** des données vers le périphérique |
| **MISO** | *Master In Slave Out* | Le périphérique **envoie** des données vers le Pi |
| **SCLK** | *Serial Clock* | Le Pi **génère l'horloge** pour synchroniser les bits |
| **CE0 / CE1** | *Chip Enable / Chip Select* | Le Pi dit « **je parle à TOI** » à un périphérique spécifique |

Le fil d'horloge est noté SCK dans la fiche et SCLK dans le détail des fils : c'est le même signal.

## Les broches SPI du Raspberry Pi

| Bus | MOSI | MISO | SCLK | Sélection |
|---|---|---|---|---|
| **SPI0** | GPIO 10 (broche 19) | GPIO 9 (broche 21) | GPIO 11 (broche 23) | CE0 : GPIO 8 (broche 24) · CE1 : GPIO 7 (broche 26) |
| **SPI1** | GPIO 20 (broche 38) | GPIO 19 (broche 35) | GPIO 21 (broche 40) | CE0 : GPIO 18 (broche 12) · CE1 : GPIO 17 (broche 11) · CE2 : GPIO 16 (broche 36) |

Vous pouvez les retrouver sur [le schéma interactif des broches](/Embedded-System-Course/parcours/chapitre-3/03-broches-gpio/) en cliquant sur le filtre « SPI ».
