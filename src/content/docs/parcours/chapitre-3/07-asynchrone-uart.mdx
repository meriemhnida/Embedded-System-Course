## Fiche UART

**UART** signifie *Universal Asynchronous Receiver/Transmitter*. C'est un protocole simple qui permet l'échange de données texte ou binaires entre **deux appareils** via **2 fils**.

| | |
|---|---|
| **Nombre de fils** | 2 (TX, RX) |
| **Type** | communication série **asynchrone** |
| **Avantages** | simple à mettre en place, très courant |
| **Limites** | un seul périphérique à la fois |

- **TX** (*Transmit*) : envoie des données ;
- **RX** (*Receive*) : reçoit des données.

## Le câblage

Le **TX** d'un appareil est relié au **RX** de l'autre, et inversement. Il n'y a **aucun fil d'horloge** : les deux appareils se sont mis d'accord à l'avance sur la vitesse de transmission (le *baud rate*, par exemple 9600 ou 115200 bauds).

## Les signaux de l'UART

| Signal | Nom complet | Direction | Rôle | Utilisation |
|---|---|---|---|---|
| **TXD** | Transmit Data | Sortie → | Émission de données | Envoie les bits de données vers l'appareil distant |
| **RXD** | Receive Data | Entrée ← | Réception de données | Reçoit les bits de données depuis l'appareil distant |
| **RTS** | Request To Send | Sortie → | Demande d'émission | Indique « Je suis prêt à envoyer des données » |
| **CTS** | Clear To Send | Entrée ← | Autorisation d'émission | Répond « OK, tu peux m'envoyer des données » |

Sur le connecteur du Raspberry Pi, l'UART principal utilise **GPIO 14 (TXD, broche 8)** et **GPIO 15 (RXD, broche 10)**. D'autres broches portent aussi des fonctions UART (TXD, RXD, RTS, CTS) : le [schéma interactif des broches](/Embedded-System-Course/parcours/chapitre-3/03-broches-gpio/) les indique dans l'encadré « Autres fonctions ».

La carte possède aussi un **port série** dédié, repérable sur [le schéma de la carte](/Embedded-System-Course/parcours/chapitre-3/02-carte-raspberry-pi-5/).

## À quoi sert l'UART ?

| Type | Fonction |
|---|---|
| GPS | Envoie position, altitude, vitesse |
| Microcontrôleur externe | Communication entre microcontrôleurs |
| Capteur de CO₂ | Mesure la concentration de CO₂ |
| Lecteur RFID | Lecture de cartes |
| Module GSM / 4G | Envoie SMS, Internet, appels |
| Écran série | Interface graphique via UART |
| Module Bluetooth | Communication sans fil série |

## Exemples de capteurs et d'actionneurs

| Composant | Rôle |
|---|---|
| **GPS NEO-6M** | module GPS |
| **HC-05 / HC-06** | module Bluetooth |
| **MH-Z19** | capteur de CO₂ |
| **SIM800L** | module GSM |
