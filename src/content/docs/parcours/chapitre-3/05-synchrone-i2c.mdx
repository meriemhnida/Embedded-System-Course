## Fiche I2C

**I2C** signifie *Inter-Integrated Circuit*.

| | |
|---|---|
| **Nombre de fils** | 2 (SDA, SCL) |
| **Type** | communication série **synchrone** |
| **Avantages** | peu de fils (2), facile à chaîner plusieurs périphériques |
| **Limites** | moins rapide que le SPI |

## Le câblage

Les deux mêmes fils relient le Raspberry Pi à **tous** les périphériques. Sur la figure, les petites impulsions de la ligne d'horloge (SCL) défilent à la même vitesse que les données (SDA).

<BusProtocole type="i2c" />

| Fil | Nom | Fonction |
|---|---|---|
| **SDA** | GPIO 2 | Transmet les **données** |
| **SCL** | GPIO 3 | Envoie le **signal d'horloge** pour synchroniser la communication |

## Les broches I2C du Raspberry Pi

- **GPIO 2 et 3** : bus I2C **principal** pour les périphériques (broches 3 et 5 du connecteur) ;
- **GPIO 0 et 1** : I2C **dédié à l'identification des cartes HAT** (broches 27 et 28).

Vous pouvez les retrouver sur [le schéma interactif des broches](/Embedded-System-Course/parcours/chapitre-3/03-broches-gpio/) en cliquant sur le filtre « I2C ».

## Exemples de capteurs et d'actionneurs

| Composant | Rôle |
|---|---|
| **BMP280** | température et pression |
| **MPU6050** | accéléromètre et gyroscope |
| **BH1750** | capteur de luminosité |
| **PCA9685** | contrôleur de servomoteurs |

Le cours cite aussi, parmi les types de périphériques I2C : température / humidité, qualité de l'air, accéléromètre / gyroscope, luminosité, horloge temps réel, magnétomètre et écran LCD.
